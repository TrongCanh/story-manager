# Theme Rules / Quy tắc Chủ đề

This document defines the color themes for the application. Themes must not affect layout, spacing, or typography.

Tài liệu này định nghĩa các chủ đề màu sắc cho ứng dụng. Các chủ đề không được ảnh hưởng đến bố cục, khoảng cách hoặc typography.

---

## 1. Light Theme / Chủ đề Sáng

- Background: white, gray-50
  - Nền: white, gray-50
- Text: gray-900, gray-700, gray-500
  - Văn bản: gray-900, gray-700, gray-500
- Border: gray-200
  - Viền: gray-200
- Primary: blue-600
  - Chính: blue-600

---

## 2. Dark Theme / Chủ đề Tối

- Background: gray-900, gray-800
  - Nền: gray-900, gray-800
- Text: gray-100, gray-300, gray-400
  - Văn bản: gray-100, gray-300, gray-400
- Border: gray-700
  - Viền: gray-700
- Primary: blue-500
  - Chính: blue-500

---

## Rules / Quy tắc

- Themes only change colors, never layout
  - Chủ đề chỉ thay đổi màu sắc, không bao giờ thay đổi bố cục
- Use Tailwind dark mode class strategy
  - Sử dụng chiến lược class dark mode của Tailwind
- Avoid pure black (#000)
  - Tránh màu đen tinh khi (#000)
- Dark theme must reduce eye strain
  - Chủ đề tối phải giảm căng thẳng cho mắt

---

**Note:** All components must be theme-compatible.

**Lưu ý:** Tất cả các thành phần phải tương thích với chủ đề.
